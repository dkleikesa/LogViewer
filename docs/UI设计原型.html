每个过滤器可选一色作为底纹（行 tint 为 13-15% alpha），同时作为左侧 3px 色条和列表小色块，形成"行色 / 列表色 / 标题色条"三处一致的视觉锚点。

过滤器行格式 对齐 TAT

aMatches "FATAL" (i)3/266
bMatches "ANR" (i)1/266
cMatches "TagService" (i)9/266
dEXCL Matches "chatty" (i)42/266
底部工作台让规则可完整横向阅读，仍沿用紧凑记法：动词（Matches/Excludes）+ 模式串 + 大小写标记（i=不敏感 / s=敏感）+ EXCL/RX 徽标；完整属性（描述、颜色编辑）点 ⋯ 菜单进入编辑对话框。悬停过滤器行可在日志区闪烁对应命中行。

三种显示模式 F3-7

全部原样显示所有行
高亮全部显示，命中行着色
仅显示只显示命中行
快捷键 Ctrl+H 在三态间循环切换。视觉感受：全部态用作"看上下文"，高亮态用作"扫重点"，仅显示态用作"聚焦目标"。
